VIBE CODING WITHOUT THE DO-OVERS第一章 / 痛点

改了又改，加了又坏

产品经理、小企业老板、职场白领用 AI 做小程序或网站，最常遇到三类返工。

01

生成的不是我要的

只好改提示词，一遍一遍推倒重来。

本书解法：切薄片＋先追问
02

新功能加不上去

好不容易做对了，后面再加功能就卡住。

本书解法：每片存档，改坏就退回
03

加上了，旧的坏了

新功能有了，原来能用的功能被改坏。

本书解法：中文验收场景＋自动测试
一位不懂开发的朋友用 n8n 做个人知识管理：AI 让他改核心程序，他照做了，几轮下来改坏好几个，只好停工。
我问他：“你用 git 管理代码版本吗？”他反问：“git 是什么？”

有人说 vibe coding 是骗局，也有人说离开技术人员的代码一文不值。我的看法：先动手踩坑，方法就藏在爬坑的过程里。
