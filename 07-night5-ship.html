第 5 晚：能上线，能交接

给别人一个能打开的网址；把成品连同证据，交给技术公司也接得住。

01

部署上线

  • 推送到 GitLab，部署到 Vercel
  • 纯前端，不用配环境变量
  • 上线后再走一遍：加功能 → 跑测试 → 存档 → 重新部署

自购域名为选修。

02

交接包三件套

小企业老板专节：把成品交给外包技术公司

  • 能运行的原型
  • git 历史：每一步让 AI 做了什么
  • 中文验收场景及其自动测试
03

毕业：码主

Code Owner：AI 负责蹬，你掌握方向，对自己的代码负责。

在交给技术公司的 README 里，写上“码主：你的名字”。
